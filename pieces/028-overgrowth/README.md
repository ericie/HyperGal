# Overgrowth

A richly layered procedural botanical illustration drawn entirely in Canvas 2D. The piece constructs roses, peonies, poppies, lilies, daisies, anemones, hydrangeas, buds, stems, and veined foliage, flattens them into one still composition, then adds the mottling and fine fibers of a printed textile.

There is no animation loop or manipulation interface. The garden renders once on opening and again only when the viewport changes or a new arrangement is requested.

Click the drawing, or press `R`, Enter, or Space, to compose a new garden.

The piece is self-contained and has no external dependencies.
