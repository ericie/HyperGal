# Knot Work

A full-browser knot field inspired by mid-century textile posters and Celtic
interlace: dark umber double-line cords on worn paper, scaled until the pattern
runs off every edge of the viewport.

The piece generates a deterministic field from a seed. Every tile consumes all
four edges, so the browser fills with continuous interlaced cord rather than
separate ornaments. Rounded turns and cross tiles alternate over-under cuts
across a subtly warped grid, keeping the structure poster-like without becoming
perfectly mechanical.

Click or press Enter/Space to reseed. Use `?seed=anything` to revisit a specific
composition.
