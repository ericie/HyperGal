# Micro Tetris

A self-playing, full-window Tetris field. Each tetromino consists of four **4×4 CSS pixel square cells**, including on high-density displays. One-pixel seams separate the four squares within each shape and the settled pile. The board has one column for every four CSS pixels of window width. No grid across the empty field, score overlay, or external dependencies.

Starts with a **sparse partly played stack occupying at most about 0.5% of the board**, confined to the bottom 10% of the window (or four cell rows in very short windows). The starting board is built by dropping a small number of real tetrominoes with imperfect placement decisions, leaving plenty of open floor. Completed historical lines are removed before the artwork starts. No seeded row is complete. Extremely narrow windows with fewer than five columns start empty.

Exactly one tetromino enters at the top center at a time and falls immediately. Gravity continues at a steady rate while the player nudges sideways, rotates, or hesitates. Some drops briefly drift the wrong way, overshoot, or try a rotation before correcting it. Every move and turn is collision-checked at the current falling height; blocked inputs never lift the piece or stop its descent. The player chooses rotations and columns that limit new holes and keep the surface even, so it can play from the partly played stack. Completed full-width rows blink before disappearing and the rows above collapse down before the next piece begins. Four-line clears get a larger, longer blink, then contract inward before collapsing. Each full-height fall takes about 2.4 seconds, including all steering and reconsideration. If the field tops out, a fresh partly played stack starts automatically. This is a full-window, self-playing Tetris artwork rather than a standard ten-column competitive game.

Click or Space pauses/resumes. R reseeds. Resizing reseeds to fit the new window. Reduced motion starts paused.
