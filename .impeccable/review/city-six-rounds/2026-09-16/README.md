# City of Signs: six code and render rounds

All six rounds rendered from the local Canvas implementation at seed 1907, 1440 × 1060. Each has a matching source snapshot. These are renderer screenshots, not generated-image assets.

1. **Tower silhouettes:** Stepped and curved edges, varied heights. [Render](01-silhouettes.png), [source](01-silhouettes.js).
2. **Motif proportions:** Compact fans, shaped walls, scaled roof pieces. [Render](02-proportions.png), [source](02-proportions.js).
3. **Connections:** Arched bridges, hanging spans, crossing stairs. [Render](03-connections.png), [source](03-connections.js).
4. **Architectural vocabulary:** Courtyards, offset arcades, fluted domes and sail pavilions. [Render](04-vocabulary.png), [source](04-vocabulary.js).
5. **Composition and detail:** Openings fitted inside profiles; wider shared spans. [Render](05-hierarchy.png), [source](05-hierarchy.js).
6. **Final integration:** Fan integrated with its tower; overhang and mobile checks. [Render](06-final.png), [source](06-final.js).

Round 5 exposed an undersized fan caused by fitting into curved contours. Round 6 restores a full-width feature bay and integrates fan polarity with the tower.

Additional final evidence: square, mobile, user screenshot proportions, two alternate seeds, and the full block catalog. Earlier uncommitted scale-pass files in the parent directory were retained.
